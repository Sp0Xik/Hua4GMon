# Безопасность

## Поддерживаемые версии

Исправления выходят только для последней версии со страницы
[Releases](https://github.com/Sp0Xik/Hua4GMon/releases).

| Версия | Поддержка |
| :----- | :-------- |
| 1.4.x  | да        |
| < 1.4  | нет       |

## Как сообщить об уязвимости

Пожалуйста, **не открывайте публичный issue**. Сообщите приватно через
GitHub: вкладка **Security → Report a vulnerability**
([форма](https://github.com/Sp0Xik/Hua4GMon/security/advisories/new)).
Опишите версию, платформу (Windows / Android), модель роутера и шаги
воспроизведения. Ответ — в течение нескольких дней; после исправления
уязвимость будет описана в CHANGELOG и в разделе Security Advisories.

## Что важно знать о программе

- Hua4GMon работает только с роутером в локальной сети через его
  штатный веб-API (библиотека huawei-lte-api) и не отправляет данные
  на сторонние серверы. Исключения — только по действию пользователя:
  проверка «белых списков» (TLS-рукопожатие с несколькими публичными
  сайтами, без передачи данных) и кнопка «Открыть на CellMapper» на
  Windows (браузер открывает карту с кодом оператора и номером вышки).
- Пароль роутера хранится только в памяти и нигде не сохраняется.
  Параметр командной строки `--password` виден другим процессам
  компьютера — на общем компьютере вводите пароль в окне программы.
- Диагностика маскирует IMEI, IMSI, ICCID, номер телефона и серийный
  номер и полностью скрывает MAC-адреса, IP и DNS. Номер соты и оператор
  остаются: по ним можно определить район вышки — учитывайте это,
  публикуя диагностику.
- Windows .exe не подписан цифровой подписью. Скачивайте его только со
  страницы Releases и сверяйте SHA256 (см. README, раздел «Установка»).
