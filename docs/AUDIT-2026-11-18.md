## Что реально запущено

- Windows, Python 3.13.2. Полный pytest с OpenSSL из установленного Git и путями Tcl/Tk для этого окружения. 557 passed, 1 skipped за 55,16 с. Пропущен тест в `tests/test_bundle_filter.py:218`, которому нужен установленный PyInstaller. Покрытие строк и ветвей `core` по методике coverage.py — 96,25%. Для двух UI это число не измерялось.
- Ruff прошёл. Mypy прошёл для 27 исходных файлов в области `core` и `tools`. Проверка совместимости установленных пакетов `pip check` и проверка diff прошли.
- Штатный `main.py --self-test` прошёл из исходников с локальными путями Tcl/Tk. XML, RSA PKCS#1 v1.5, OAEP и создание окна Tk 8.6.15 успешны. Проверки Kivy выполнялись на Windows.
- Дополнительные примеры в таблицах выполнялись на синтетических ответах и чистых функциях. Ни одной команды изменения настроек реальному модему в ходе аудита не отправлялось. Свежие EXE и APK из данной рабочей копии не собирались. Проверка реальной авторизации, антенны, восстановления связи, Band Lock и 5G на конкретной прошивке остаётся стендовой.

Порядок работы: сначала пункты 1–3 (настройки модема и экспорт диагностики), затем 4–5 (достоверность сот и MIMO), затем 6–15. Отдельно от изменений радиологики — обновления инструментов и испытания APK. Для аппаратной приёмки нужны исходные и перечитанные настройки на LTE и NR, проверка прямого и маршрутизируемого подключения и запуск тех же артефактов, которые пойдут в релиз.
