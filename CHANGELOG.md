# Changelog

Все значимые изменения в этом проекте документируются здесь.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование: [SemVer](https://semver.org/lang/ru/).

## [1.4.0] — 2026-09-24

Релиз модернизации: переход на huawei-lte-api 2.0.1, общее ядро сессии
для обеих платформ, динамический Band Lock, RF-аналитика для наведения
антенны, доработка Windows и Android, релизная подпись APK.

### Добавлено
- **Тестовый режим на Windows** (раньше — только Android) на новом
  симуляторе модема: вращение антенны, смена сот, агрегация, 5G NSA,
  реакция на Band Lock, смену антенны и перезагрузку. Тестовый режим
  идёт через тот же код сессии, что и реальный роутер.
- **Автопоиск роутера** по типовым адресам (192.168.8.1, 192.168.1.1,
  192.168.3.1 и др.).
- **Динамический Band Lock**: список бэндов берётся из модема
  (net-mode-list), замеченные в эфире — первыми; кнопки «Отметить
  текущие» и «Вернуть как было»; предупреждение, если выбор отключит
  текущий бэнд или агрегацию; после записи настройки перечитываются и
  сверяются. Распознаются все LTE-бэнды 3GPP (1–88).
- Подготовка к **5G**: NR-метрики (RSRP/SINR/RSRQ, ARFCN, PCI, NCI),
  определение 5G NSA/SA; на 5G-модемах Band Lock не выключает 5G.
- **RF-аналитика**: частота DL по EARFCN; «Δ до пика»; стрелка
  тенденции по выбранной метрике (по умолчанию SINR) с медианным
  фильтром и гистерезисом, сброс при смене соты; события смены соты;
  таблица лучших сот сессии; CQI и состояние потоков MIMO; оценка
  мощности передатчика; RRC; состояние мобильных данных; советы
  монтажнику; непрерывная оценка качества (реагирует на 1–2 дБ).
- График: автомасштаб, линия пика, признак «нет свежих данных».
- **Переподключение мобильной связи** без перезагрузки роутера; после
  перезагрузки программа переподключается сама.
- **Диагностика** (сырые ответы API в JSON, идентификаторы замаскированы):
  Windows — сохранение в файл, Android — копирование в буфер обмена.
  Шаблон issue на GitHub.
- Windows: High DPI (масштаб 100–200 %), крышный режим на том мониторе,
  где открыто окно, с «Δ до пика»; горячие клавиши F11 / Ctrl+R / Ctrl+M;
  CSV, который Excel открывает по колонкам (UTF-8 с BOM, «;» и десятичная
  запятая для русского интерфейса); свойства файла .exe (VERSIONINFO).
- Android: экран не гаснет во время мониторинга; опрос ставится на паузу,
  когда приложение свёрнуто; кнопка «Назад» (экраны → монитор, на
  мониторе — двойное нажатие для отключения); режим «Солнце» с высоким
  контрастом; звук-парктроник; нижняя панель «Звук / Пики / Меню» для
  работы одной рукой; крупная выбранная метрика; живое обновление экрана
  «Информация»; лучшие соты сессии.
- Проверка «белых списков»: TLS-рукопожатие с SNI вместо голого TCP,
  различение блокировки по IP и по имени сайта; все цели параллельно.

### Изменено
- **huawei-lte-api 2.0.1** (было `>=1.10,<2`). Перезагрузка — через
  `set_control(REBOOT)` (старый `device.reboot()` в 2.0 удалён), режимы
  сети и антенны — через enum библиотеки, выход из роутера при
  отключении. Вся работа с библиотекой — в одном модуле `core/router.py`.
- Все зависимости обновлены и закреплены; минимальная версия Python — 3.11.
- Опрос и переподключение — общий фоновый поток для Windows и Android:
  у каждого эндпоинта своя частота, неподдерживаемые моделью больше не
  опрашиваются; повторный вход при истечении сессии; при неверном пароле —
  одна попытка без повторов (защита от блокировки входа, код 108007).
- Понятные сообщения об ошибках; исправлена подсказка по кодам
  (108006 — неверный логин или пароль, 108007 — блокировка входа).
- Band Lock сохраняет настройки 2G/3G (NetworkBand); «AUTO» не включает
  2G/3G, если до программы был режим «только 4G».
- Агрегация определяется по данным роутера (CurrentNetworkTypeEx), а не
  только по полю band; имя оператора — из ответа роутера.
- RSRQ оценивается как «загрузка/помехи», пороги −10 / −15 / −20 дБ.
- Режим MIMO подписывается как схема передачи (TM), а не число антенн.
- Диапазоны осей графиков расширены до 3GPP (например, RSRP −140…−44).
- CI: GitHub Actions v7, тесты на Python 3.11–3.14 и на Windows, UI-тесты
  обеих платформ, контроль покрытия, Dependabot, проверка .exe после
  сборки, SHA256 для APK, релизная подпись APK, проверочная сборка на
  Buildozer 1.6.0.

### Исправлено
- Обновление интерфейса Windows из фонового потока — теперь через
  потокобезопасную очередь.
- Звук на Windows больше не создаёт поток на каждый сигнал.
- Отключение и закрытие программы не подвисают, пока роутер не ответит.
- Ширина канала «20MHz» больше не принимается за бэнд B20 (ложная CA).
- Граничные значения вида `>=-51dBm` и `<-140dBm` разбираются.
- MCS 29–31 (повторные передачи) не выдаются за конкретную модуляцию.
- Исправления после записи 1.3.0: фильтр правдоподобия для поля band
  (Huawei B636) и разбор DL-EARFCN из строки `DL:… UL:…`.

### Удалено
- Фиксированный список из девяти бэндов (заменён списком из модема).
- Настройка `android.usesCleartextTraffic` — это не ключ Buildozer, она
  ни на что не влияла.

### Безопасность
- huawei-lte-api 2.x пишет пароль в DEBUG-лог — логгер библиотеки
  ограничен уровнем INFO.
- Диагностика маскирует IMEI, IMSI, ICCID, номер, серийный номер, MAC и
  WAN IP.
- APK подписывается постоянным ключом из секретов репозитория (раньше —
  одноразовым ключом CI). Обновление с 1.3.0: один раз удалить старую
  версию.

## [1.3.0] — 2026-07-12

Релиз стабилизации: полный аудит кода, безопасности и зависимостей.

### Добавлено
- Полноэкранный график на Android: разметка осей (значения, заголовок,
  подпись оси X, маркер последнего значения) и альбомная ориентация —
  разворачивается весь контент, включая кнопку, касания работают верно.
- Вкладка «Сеть» подтягивает **текущие настройки модема**: отмеченные
  бэнды Band Lock и выбранный режим антенны подставляются прямо в
  элементы управления. Только GET-запросы — существующая фиксация на
  модеме не затрагивается. Если модель не отдаёт endpoint, показывается
  предупреждение (пустые чекбоксы иначе выглядели бы как «фиксации нет»).
- Модуляция DL и UL (MCS с расшифровкой в QPSK/16/64/256-QAM), мощность
  передатчика, режим MIMO, TAC, ширина канала UL, месячный трафик —
  на обеих платформах. Поля опциональны: показываются, если роутер их
  отдаёт.
- Логирование в Android-версии (видно в `adb logcat`) — раньше ошибки
  на устройстве терялись молча.
- Тесты: проверка, что все имена, импортируемые из `core`, существуют
  (ловит рассинхрон до сборки APK), и что `on_pre_enter` не обращается
  к KV-виджетам напрямую. Всего 89 тестов.

### Изменено
- Оценка сигнала переформулирована честнее: «Отличный/Хороший/Средний/
  Слабый сигнал» вместо обещаний конкретного качества видео («4K»,
  «FullHD») — RSRP/SINR отражают радиокачество, а не пропускную
  способность (на неё влияют CA, загрузка соты, MCS, backhaul).
- Вердикт теста белых списков смягчён: «Вероятна фильтрация» вместо
  категоричного «включены» — TCP-проба на :443 не доказывает
  доступность на уровне TLS/HTTP на 100%; добавлена подсказка
  перепроверить в браузере.
- Расширен набор правил линтера: добавлены `UP` (современный синтаксис),
  `SIM` (упрощения), `C4` (генераторы). Код приведён к ним полностью.
- Типизация модернизирована под Python 3.10+ (`dict` вместо `Dict`,
  `X | None` вместо `Optional[X]`).
- PyInstaller обновлён до 6.21+ (был 6.10).
- Сборочный стек Android (buildozer 1.5.0, python-for-android
  v2024.01.21, NDK 25b, cython 0.29.36) намеренно оставлен закреплённым:
  свежие версии тянут Python 3.14, где ломается `pyjnius`.

### Исправлено
- Краш Android на старте: `on_pre_enter` первого экрана вызывается до
  привязки KV-виджетов — обращение к ним теперь через `ids.get()`.
- Зависший статус «Подключение...» на экране подключения после отключения.
- Двойное нажатие «Подключиться» на Android больше не поднимает второй
  воркер-поток.
- Тихие `except: pass` заменены на логирование — ошибки больше не
  теряются.
- Толщина линии графика ограничена сверху (в полноэкранном режиме была
  слишком жирной).

### Безопасность
- Аудит: `eval`/`exec`/`pickle`/`subprocess` не используются;
  захардкоженных секретов нет; пароль роутера живёт только в оперативной
  памяти и никогда не пишется на диск.

## [1.2.0] — 2026-06-28

Крупный релиз: вторая платформа (Android), выделение общего ядра в
пакет `core/`, локализация RU/EN.

### Добавлено
- **Android-версия** (Kivy + Buildozer) с полным функционалом монитора:
  RSRP/RSSI/SINR/RSRQ с пиками и цветовой индикацией, стрелка тенденции,
  джиттер, графики с полноэкранным режимом и выбором параметра, экран
  «Инфо» (вышка, SIM/устройство, состояние), экран «Сеть» (Band Lock,
  переключение антенн, перезагрузка, тест белых списков), подсказка по
  ошибкам подключения, тестовый режим с демо-данными для эмулятора.
  Сборка APK через GitHub Actions.
- **Двуязычный интерфейс** (русский / английский) с переключением «на
  лету»; вся текстовая часть вынесена в `core/i18n.py`.
- Общий пакет **`core/`** (constants, parsers, signal_analysis,
  whitelist, i18n), переиспользуемый Windows- и Android-версиями.
- Индикатор тенденции RSRP (↑ / → / ↓) с подсказкой для монтажника.
- Авто-переподключение к роутеру при обрыве с экспоненциальным backoff.
- Экспорт сессии измерений в CSV для отчётов клиенту (Windows).
- CLI-аргументы `--ip`, `--password`, `--verbose`, `--version`.
- Расшифровка LTE-бандов из любых форматов API (`'7'`, `'LTE BAND 20'`,
  `'B3+B7'`, битмаски `0x40`) в человекочитаемый вид с указанием частоты.
- Поле EARFCN и fallback-определение band по EARFCN.
- Блок «SIM / Устройство»: IMEI, IMSI, ICCID, номер, серийный номер,
  модель, прошивка.
- Кнопка перезагрузки роутера.
- Тест «белых списков (РФ)» через TCP-пробы на `:443`.
- Аудио-помощник и «крышный режим» (Windows).
- Расширенный список операторов (PLMN_MAP) для РФ, РБ, KZ, UA.
- Band Lock для девяти диапазонов РФ/СНГ: B1, B3, B5, B7, B8, B20, B38,
  B40, B41.
- Тесты на pytest (`tests/test_core.py`), линтер ruff, CI lint+test+build
  для обеих платформ.

### Изменено
- График переписан с matplotlib на голый `tk.Canvas` (Windows) и Kivy
  canvas (Android) — без тяжёлых зависимостей.
- Монолитный `main.py` разделён: вся логика в `core/`, в `main.py`
  остался только UI-слой Tkinter.
- Экран мониторинга Android переведён на пропорциональную раскладку
  (`size_hint`) — адаптируется под телефоны и планшеты без прокрутки.
- Парсинг `cell_id` отбрасывает заведомо невалидные значения.
- `extract_number` использует строгий `re.fullmatch`.

### Исправлено
- Потокобезопасность: фоновый поток мониторинга не падает при
  обнулении клиента во время `disconnect()`; смена экрана из фонового
  потока на Android — только через главный поток.
- Совместимость крипто-зависимости на Android: `pycryptodomex`
  (нет рецепта p4a) заменён на `pycryptodome` с перенаправлением
  неймспейса `Cryptodome` → `Crypto`.
- Корректный `logout()` при отключении.
- Полная локализация RU/EN: метки уровней сигнала, бэнды, режимы антенн,
  вердикты белых списков, подписи графиков.

### Удалено
- Сохранение пароля и IP на диск — программа портативна.
- Зависимости `matplotlib` и `requests`.
